# BarberPro

Sistema de gestão para barbearias desenvolvido em PHP e MySQL.

## Recursos

- Cadastro de clientes, serviços, profissionais e logins
- Agenda diária e semanal
- Agendamento público
- Notificações de novos horários
- Funções e permissões
- Estoque simplificado
- Folgas e bloqueios de profissionais
- Lista de espera
- Histórico de alterações
- Relatórios e backups

## Requisitos

- PHP 8.2 ou superior
- MySQL/MariaDB
- Apache

## Instalação local

1. Copie os arquivos para a pasta pública do Apache.
2. Importe `database/barbearia_system.sql` no MySQL.
3. Ajuste os dados de conexão em `database.php`.
4. Acesse o sistema pelo navegador.

Altere imediatamente o login e a senha iniciais após a instalação.
